## 核心内容速览

### 编码架构（三层 + 两类用途）

1. **产品族码 SKU** — 标识「是什么产品」，后台主数据，长期稳定
2. **单品码 UIN** — 标识「是哪一件」，全局唯一、终身不变、不可推测
3. **追溯载体** — 明码 + 加密二维码 / RFID，把身份固化到实物

### 覆盖行业（演示工具 5 个 Tab）

| 行业 | 规则要点 |
|---|---|
| 食品饮料 | SKU 分类骨架 + UIN，批次与保质期管理 |
| 3C 电子 | SN 序列号，绑定保修与售后 |
| 化妆品 | 色号 / 规格，防伪验真与防窜货 |
| 服装鞋帽 | SKU 按「款-色-码」三维管理，吊牌码贯穿渠道 |
| 医疗器械 UDI | 按 GS1 标准：GTIN-14（Mod10 校验位）+ AI 应用标识符 (01)(11)(17)(10)(21) |

### 追溯链路（7 节点）

原料生产 → 生产赋码 → 包装关联 → 入库出库 → 渠道配送 → 终端销售 → 消费者/售后

## 使用说明

- **演示工具**：浏览器打开 `demo/index.html`，选择行业 Tab 填写表单即可生成编码；生成的码自动存入本地码库，可在「追溯查询」输入编码查看全生命周期履历。数据仅存本地浏览器，不涉及后端。
- **规范文档**：`docs/企业产品一物一码追溯编码规范.docx` 为正式发布稿，含封面、目录、页码及 13 章正文 + 2 附录。
- **重新排版**：修改 `docs/编码规范_源稿.md` 后，调整 `scripts/build_html.py` 中的 `SRC`/`OUT` 路径，运行脚本重新生成 HTML，再转换为 DOCX。
